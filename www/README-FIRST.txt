SONGWRITER'S JOURNAL — Android PWA TEST

1. Create a NEW PUBLIC GitHub repository, e.g. songwriter-journal-test.
2. Upload index.html, manifest.webmanifest, sw.js and the icons folder (both PNGs). Do not upload your personal journal entries or backups.
3. Repository Settings > Pages > Build and deployment: Deploy from a branch > main > /(root) > Save.
4. Wait for the Pages URL to appear (usually https://USERNAME.github.io/songwriter-journal-test/).
5. Open that HTTPS URL in Chrome on Android. From Chrome menu, choose Install app or Add to Home screen.
6. Create a TEST idea, tap Record, allow microphone, stop and play back the recording. Export a backup and verify it downloads.

IMPORTANT: The HTTPS version has separate browser storage from your previously opened content:// file. Export backup from the old version, then restore into the new version if you want the old test ideas. Never rely on browser storage as the only copy of valuable songwriting. This prototype does not sync devices and is not a secure multi-user service. A public GitHub Pages site means anyone with the URL can load the app; journal data remains local to each browser, not in the repository.
